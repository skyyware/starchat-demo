## Datenschutz

Der oben genannte Anbieter ist für die Verarbeitung personenbezogener Daten
auf chat.stage.dev verantwortlich. Datenschutzanfragen richten Sie an dieselbe
Kontaktadresse.

### Ihr Gespräch

Sie können die Dokumentation ohne Konto und ohne Chat lesen. Wenn Sie eine
Frage absenden, senden wir sie mit einem begrenzten Teil Ihres Gesprächs und
ausgewählten öffentlichen Quellen an OpenAI. Dort wird die Antwort erstellt
und geprüft. Die Verbindung nutzt Codex über das bestehende ChatGPT-Konto des
Betreibers. Geben Sie keine Passwörter oder vertraulichen Informationen ein.
Antworten und Code können Fehler enthalten.

Ihr Browser speichert das Gespräch auf diesem Gerät, bis Sie **Neues Gespräch**
wählen oder die Website-Daten löschen. Fehler beim Speichern oder Löschen zeigt
die Oberfläche an. Auch der Browser kann Daten nach seinen eigenen Einstellungen
entfernen. Die Anwendung führt kein Gesprächsarchiv auf dem Server und schreibt
Fragen und Antworten nicht in ihre Anwendungsprotokolle.

Beim ersten Besuch der neuen Chat-Adresse kann Ihr Browser einen vorhandenen
Stage-Verlauf von stage.dev übernehmen. Die Übernahme erfolgt nur im Browser,
ersetzt keinen bereits hier vorhandenen Verlauf und erhält die alte Kopie.

Das Löschen im Browser entfernt keine bereits an OpenAI gesendeten Daten.
Für die Verarbeitung, Speicherung und internationale Übermittlung durch OpenAI
gelten dessen jeweilige Nutzungsbedingungen und Dateneinstellungen. Siehe
[OpenAIs Datenschutzhinweise](https://openai.com/policies/eu-privacy-policy/)
und [Datenschutzeinstellungen für Codex](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan).

Fragenlinks können Text in der Adresse enthalten. Der Browser entfernt ihn,
nachdem er ihn als bearbeitbaren Entwurf geladen hat. Erst beim Absenden wird
das Modell aufgerufen. Die ursprüngliche Adresse erreicht vorher den Server
und möglicherweise weitere Infrastruktur. Verwenden Sie in solchen Links keine
personenbezogenen oder vertraulichen Informationen.

### Projekt-Downloads

Zum Einstieg kann der Chat eine vorbereitete Minimalanwendung anbieten.
Dieser von uns bereitgestellte Starter enthält kein Gespräch und keine persönlichen
Angaben. Der Server hält eine vorbereitete Kopie vor. Ihr Download braucht keine
zusätzliche Modellanfrage.

Für ein individuelles Projekt senden wir nach der Antwort automatisch das aktuelle,
begrenzte Gespräch und gegebenenfalls die bisherigen Projektdateien an denselben
Anbieter, um einen neuen Stand zu erstellen und zu prüfen. Ein Download erscheint
erst, wenn die ZIP-Datei fertig ist. Der Klick darauf löst keine weitere
Modellanfrage aus. Der Dienst führt Besucherprojekte nicht aus. Ihr Browser speichert
das letzte Projekt neben dem Gespräch. Ein neuer Stand ersetzt den älteren;
**Neues Gespräch** löscht ihn. Bereits auf Ihr Gerät heruntergeladene Dateien bleiben
dort. Der Server entfernt temporäre individuelle ZIP-Dateien nach der Auslieferung
und führt kein Archiv von Besucherprojekten. Änderungen nach dem Herunterladen
werden nicht in den Chat zurückgeladen.

Analysedienste. Der Browserspeicher dient dem angefragten Gespräch. Gemeinsame Schriften und Designdateien werden von stage.dev unter demselben
Betreiber geladen. Weitere Anwendungsdateien werden hier bereitgestellt. Externe Websites erhalten eine
Anfrage, wenn Sie deren Links öffnen.

Zur Bereitstellung und zum Schutz der Website protokolliert der Server
IP-Adresse, Zeitpunkt, HTTP-Methode, Pfad ohne Abfrageparameter, Protokollversion,
Status und Antwortgröße. Zugriffsprotokolle enthalten weder User-Agent noch
Referrer. Fehlerprotokolle können technische Fehler und Anfragedetails enthalten.
Diese Protokolle rotieren täglich. Neben der aktuellen Datei bleiben je
Protokoll bis zu 14 Tagesarchive erhalten; ältere Archive werden bei der nächsten
Rotation gelöscht. Betreiber und Hosting-Dienstleister greifen bei Bedarf darauf zu.

Die Auslieferung der Website und Sicherheitsprotokolle dienen unserem
berechtigten Interesse an ihrem Betrieb und Schutz nach Artikel 6 Absatz 1
Buchstabe f DSGVO.

über Websites hinweg.
